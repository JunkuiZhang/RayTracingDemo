# 阶段 11F-R：RR 有界收口验收记录

日期：2026-08-13
目标 GPU：NVIDIA GeForce RTX 4060 Laptop GPU
固定 Streamline：v2.12.0
范围：仅 RR 有界验收 runner；没有实现 11G、Frame Generation、swap chain/proxy device/factory 改造。

## 1. 实现范围

新增 `scripts/stage11_rr_acceptance.ps1`，不复制 Stage 10 runner 的渲染流程：

- Native、DLSS SR、NRD 基线通过 `scripts/stage10_acceptance.ps1 -CaseName ...` 单 case 运行，读取其 `summary.json`；
- 本脚本只调度 RR Quality/Balanced/Performance、Triangle 动画和 RR Debug；
- 每个实际 D3D/GUI 子进程都保存 args、stdout、stderr、exit JSON，并使用 `Start-Process`、有界 `WaitForExit` 和 PID 树终止；
- benchmark stdout 的可解析 JSON 行数必须恰好为 1；Streamline 签名校验产生的非 JSON stdout 原文保留并记录，不会掩盖第二条 JSON；
- gate 覆盖 RR profile、active RR pass、SVGF/NRD/普通 SR 隐藏成本、GPU idle wait、optimal extent、显存比例、Reflex/PCL 对账、错误输出和 Debug InfoQueue；
- `-SelfTest` 不启动 GPU，覆盖空 JSON/超时/多 JSON 及上述主要负例。

没有修改 shader、RR 资源、ToneMap、曝光、采样、renderer 算法、ROI 或既有阈值。
