# 阶段 11：RR 镜面虚拟边界修复记录

日期：2026-08-13  
目标 GPU：NVIDIA GeForce RTX 4060 Laptop GPU

## 1. 问题与根因

左侧低粗糙度金属箱的正面在靠近地板处出现轻微水波纹。静止帧的物理表面 ID、
主运动向量和原边界 mask 都完全稳定，但 RR 最终颜色仍在镜面内部变化。原稳定层只看
相机首个物理交点，因此无法识别镜面里由反射命中形成的虚拟地板/物体边界。

场景资产还存在一个独立放大因素：金属箱隐藏底面与 Cornell 地板同为 `y=-1.0`，形成
完全共面的重合三角形。

## 2. 采用的最佳实践

1. 保留 DLSS RR 官方要求的稠密 specular motion vector，不同时提交 specular hit distance。
   静止场景的镜面运动为零是正确契约，不应人为注入抖动。
2. 借鉴 NRD Primary Surface Replacement（PSR）：对静态纯平面镜追踪确定性的主反射，
   把反射命中的位置、法线、上一帧位置和表面身份展开到虚拟世界。
3. 虚拟 guide 只供项目自己的 post-RR 边界稳定层使用，不替换 RR 的 noisy HDR、深度、
   normal/roughness、主运动或 specular motion 输入。
4. 为虚拟表面 ID 保留高位命名空间，避免“镜中地板”和真实地板被误认为同一边界。
5. 只在虚拟/物理边界附近积累历史；非边界像素继续精确透传 RR 输出。
6. 动画镜面在没有上一帧镜面法线变换时回退到物理 guide，不能制造看似合理但错误的
   虚拟运动。
7. 清理共面接触几何：不透明金属箱轻微嵌入地板，既不产生悬空缝，也不保留重合底面。

## 4. 验证

- `cargo test --features streamline-rr --locked`：154 个主程序测试与 6 个 `image_diff`
  测试全部通过。
- `cargo build --release --features streamline-rr --locked`：通过。
- 1280x720、DLSS RR Quality、121/122 SPP 相邻帧：

| ROI | 修复前 MAE | 修复后 MAE | 修复前/后最大通道差 | RGB 差值大于 2 |
| --- | ---: | ---: | ---: | ---: |
| 左箱镜面下缘 `478,565,157,62` | 0.1656 | 0.0983 | 6 / 1 | 69 / 0 |
| 实际接触线 `470,625,175,20` | 0.1636 | 0.1532 | 1 / 1 | 0 / 0 |
| 邻近普通地板 `350,600,120,50` | 0.0666 | 0.0621 | 1 / 1 | 0 / 0 |

镜面目标 ROI 的 MAE 下降约 41%，较大跳变归零；邻近普通地板没有出现全屏加重平滑。
新的 object/material ID 与 history-rejection 调试图能看到镜面内部的虚拟边界，静止 motion
调试图仍为全黑。

捕获位于被忽略的 `output/codex-rr-virtual-boundary/`，不提交 PNG。

## 5. 范围

本轮只对项目的静态 `LegacyMetal` 纯镜面启用虚拟 guide。带纹理的通用 glTF 金属、曲面
镜子和动画镜面仍使用保守物理 guide；将来若扩展这些场景，需要提交完整的上一帧镜面
变换/曲率信息，而不是放宽当前阈值或扩大全屏滤波半径。
