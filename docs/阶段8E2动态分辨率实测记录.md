## Codex review 修复与长时复核

首轮 review 修复了以下问题：

- `--target-gpu-ms` 现在先检查原始毫秒值，再转换为整数微秒；Release 已确认拒绝会被四舍五入进范围的 `3.9996` 和 `50.0004`。
- dynamic JSON 增加单元测试，覆盖 config、最终 state、measurement baseline delta、lifetime totals、stale sample 和 fixed null。
- README、阶段 8 总计划、主实施方案和本文状态同步，不再错误显示“8E-2 尚未实现”。
- resize/reload 的 `GpuProfiler::invalidate()` 只清 UI rolling stats，不再在 benchmark 计时和其他 baseline 未重启时单独清空 GPU/CPU accumulator；显式 `begin_benchmark_measurement()` 是唯一 measurement epoch 起点。

RTX 4060 Laptop Release 使用 1920×1080、目标 4.0 ms 运行 600 秒：

- benchmark 正常退出，无 Device Removed；最终 profiler 有效样本 114,293。
- lifetime 降档 6 次，measurement 降档 5 次；最终 requested scale 0.70。
- 最终 retired generation 为 0，high-watermark 为 1。
- local usage/budget 为 361,472,000/7,537,164,288 B（4.8%），未出现持续阶梯增长。
- 运行期间窗口发生两次真实 output resize，最终 output 为 1940×1080；measurement generation create/switch 为 7/7，其中 5 次来自动态降档、2 次来自 resize，`gpu_idle_wait_count=2` 与两次合法 resize 对账。
- 因 resize 触发了旧实现的 accumulator 口径问题，本次 600 秒 pass 分布不用于正式性能比较；资源生命周期结果仍有效。

修复 accumulator 后执行 8 秒自动双 resize 复测：`passes.total.valid_samples=770`，controller measurement valid/stale 为 758/12，满足 `770 = 758 + 12`；generation create 8 次由 6 次动态切换和 2 次 resize 组成，history reset 8 次，最终 retired 为 0、high-watermark 为 1。由此确认所有 measurement 字段重新覆盖同一 benchmark interval。
