## 实现摘要

- `ReconstructionFrameState` 统一提供当前/上一帧非抖动矩阵、viewZ、稠密 motion、
  diffuse/specular albedo、hit distance、reset 和 extent；SVGF 与 NRD 共用输入来源。
- NRD C ABI 固定 v4.17.3，源码通过本地离线 FetchContent 构建；桥接层不跨 ABI 传递
  C++ 异常、allocator 或 COM 所有权。
- NRD 资源和 backend 属于 `RenderResourceGeneration`，F3、固定内部尺寸切换和动态
  尺寸切换都事务化创建新代，旧代按 fence 退休；切换不调用 GPU idle wait。
- NRD 调度前后显式恢复应用 descriptor heap，并按 NRI direct command list 的实际
  `SHADER_RESOURCE = NON_PIXEL|PIXEL` 状态跟踪。两个 NRD 输出在下一帧 prep 前显式
  转回 UAV，避免输出复用时产生错误的 `0xC0/0x40` barrier。
- inactive profiler pass 使用 `null`，只 resolve 当前 denoiser 写入的 timestamp 区间；
  只在对应 frame fence 完成后读取 query/readback。
