## 实现摘要

- `ReconstructionFrameState` 统一提供当前/上一帧非抖动矩阵、viewZ、稠密 motion、
  diffuse/specular albedo、hit distance、reset 和 extent；SVGF 与 NRD 共用输入来源。
- NRD C ABI 固定 v4.17.3，源码通过本地离线 FetchContent 构建；桥接层不跨 ABI 传递
  C++ 异常、allocator 或 COM 所有权。
- NRD 资源和 backend 属于 `RenderResourceGeneration`，F3、固定内部尺寸切换和动态
  尺寸切换都事务化创建新代，旧代按 fence 退休；切换不调用 GPU idle wait。
- NRD 调度前后显式恢复应用 descriptor heap，并按 NRI direct command list 的实际
  `SHADER_RESOURCE = NON_PIXEL|PIXEL` 状态跟踪。两个 NRD 输出在下一帧 prep 前显式
  转回 UAV，避免输出复用时产生错误的 `0xC0/0x40` barrier。
- inactive profiler pass 使用 `null`，只 resolve 当前 denoiser 写入的 timestamp 区间；
  只在对应 frame fence 完成后读取 query/readback。
- NRD prep 现在从世界位置和相机位置计算真实视线方向，以显式 metallic 重建 F0，
  再把 diffuse albedo/F0 交给官方 `NRD_MaterialFactors`；不再把 EnvBRDF 结果误当 F0。
- reconstruction motion 改为 `RGBA16F` 2.5D 数据：XY=`previous-current` pixels，
  Z=`viewZprev-viewZ`，bridge scale=`[1/width,1/height,1]`。当前 UV 从实际抖动命中点
  投影，因此静止子像素表面的 motion validation 为零，不再把采样抖动当表面运动。
- `NewFrame()` 先于 common/denoiser settings；混合 proposal 对同一 continuation 方向
  同时估计 diffuse/specular，因此两路非零 estimator 共享 child 第一跳 hitT；只有真正
  跳过的信号才写 0。REBLUR 白噪声历史上限为 60 帧。
- DXR UAV 15/16/17 现在固定为 diffuse hitT、specular hitT、primary emissive；Rust 用
  显式寄存器号建表，长度断言与 HLSL 声明测试共同阻止同类错位回归。
- 启用 `nrd` feature 时，构建脚本把 NRD、NRI、MathLib、ShaderMake 和 D3D12MA 的
  固定许可/通知复制到可执行文件目录。

## 有界窗口交互、生命周期与 hot reload

本轮没有执行 600/1800 秒长测。Release 真实窗口接受 Win32 键消息，Debug 真实窗口
执行源码变更触发的热重载；原始日志保存在被忽略的下列目录：

- `output/stage9-interactive-probe-20260810-020510/`
- `output/stage9-hot-reload-probe-20260810-021312/`
- `output/stage9-f3-retire-fence-probe-20260810/`

结果：

- F3 完成 `svgf → nrd-reblur → svgf`，两次都 `history_reset=1`、`idle_waits=0`；修正
  遥测后旧 generation 的真实 `retire_fence` 分别为 `761` 和 `1235`，不是新 generation
  尚未提交时的错误初值 0。
- F1 严格走完并回环 `raw → albedo → normal-roughness → depth → motion → variance →
  history-rejection → history-length → object-material-id → specular-hit-distance →
  nrd-validation → final`。
- F2 fixed scale 严格走完 `1.00 → 0.83 → 0.75 → 0.67 → 1.00`；对应内部尺寸依次为
  `1280×720 → 1056×592 → 960×536 → 856×480 → 1280×720`，每次都创建新 generation。
- output resize 到 `2174×1449`、最小化和恢复后进程保持存活；恢复创建新 generation
  并显式 reset history。
- 首次 hot reload 审计发现 reloader 只观察 Stage 9 HLSL，却没有编译/替换 NRD prep
  和 compose pipeline。`94a05d8` 将两者及 NRD 官方 HLSL include 目录加入 Debug
  reloader，并在全部 pipeline 创建成功后一次性提交替换，避免半更新状态。
- 对 `stage9_nrd_compose.hlsl` 增加再移除无语义注释，两次都输出
  `Shader 热重载成功`；进程退出前 `D3D12 Debug InfoQueue：0 条消息`。临时注释已还原，
  未进入提交。

以上证据关闭的是输入分发、模式切换、资源代际和 pipeline 重建，不代表各 F1 画面的
视觉内容、连续相机运动或高光稳定性已经由人工签收。
