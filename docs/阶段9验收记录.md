## 实现摘要

- `ReconstructionFrameState` 统一提供当前/上一帧非抖动矩阵、viewZ、稠密 motion、
  diffuse/specular albedo、hit distance、reset 和 extent；SVGF 与 NRD 共用输入来源。
- NRD C ABI 固定 v4.17.3，源码通过本地离线 FetchContent 构建；桥接层不跨 ABI 传递
  C++ 异常、allocator 或 COM 所有权。
- NRD 资源和 backend 属于 `RenderResourceGeneration`，F3、固定内部尺寸切换和动态
  尺寸切换都事务化创建新代，旧代按 fence 退休；切换不调用 GPU idle wait。
- NRD 调度前后显式恢复应用 descriptor heap，并按 NRI direct command list 的实际
  `SHADER_RESOURCE = NON_PIXEL|PIXEL` 状态跟踪。两个 NRD 输出在下一帧 prep 前显式
  转回 UAV，避免输出复用时产生错误的 `0xC0/0x40` barrier。
- inactive profiler pass 使用 `null`，只 resolve 当前 denoiser 写入的 timestamp 区间；
  只在对应 frame fence 完成后读取 query/readback。
- NRD prep 现在从世界位置和相机位置计算真实视线方向，以显式 metallic 重建 F0，
  再把 diffuse albedo/F0 交给官方 `NRD_MaterialFactors`；不再把 EnvBRDF 结果误当 F0。
- reconstruction motion 改为 `RGBA16F` 2.5D 数据：XY=`previous-current` pixels，
  Z=`viewZprev-viewZ`，bridge scale=`[1/width,1/height,1]`。当前 UV 从实际抖动命中点
  投影，因此静止子像素表面的 motion validation 为零，不再把采样抖动当表面运动。
- `NewFrame()` 先于 common/denoiser settings；SVGF 后端保留共享 continuation hitT 的
  mixture estimator。镜面画质复验后，NRD 只在主表面使用 Bayer 分层 probabilistic
  lobe split，并启用 `AREA_3X3` hit-distance reconstruction；后续 bounce 仍用 mixture
  estimator。REBLUR 历史上限为 60 帧。
- DXR UAV 15/16/17 现在固定为 diffuse hitT、specular hitT、primary emissive；Rust 用
  显式寄存器号建表，长度断言与 HLSL 声明测试共同阻止同类错位回归。
- 启用 `nrd` feature 时，构建脚本把 NRD、NRI、MathLib、ShaderMake 和 D3D12MA 的
  固定许可/通知复制到可执行文件目录。

## 镜面/玻璃生产级重建补强（2026-08-12）

固定视角的 128 帧和 512 帧复验确认，镜中地面与玻璃顶面的雪花不是继续
增加 REBLUR 历史就会消失的普通方差：高光镜面的一次随机 lobe 选择和玻璃
输运会在不同路径之间切换，单靠后端降噪会丢失稳定的重建对应。本轮不再
调大历史参数，而是改为处理这两类输入的专用路径：

| Commit | 改动 | 结果 |
| --- | --- | --- |
| `8c54197` | 为 NRD 增加单平面静态镜面 Primary Surface Replacement（PSR） | 镜中地面使用虚拟反射表面的完整 G-buffer，不再把镜面本身当成降噪表面 |
| `6207d74` | NRD 相机可见玻璃首个入/出界面同时追踪反射和折射 | 使用 Fresnel 权重、独立 Sobol 维度、TIR 处理和有界深度，消除玻璃顶面的逐帧 lobe 切换 |
| `3f1d5e7` | 强化 material guide，并为移动镜面和连续镜面增加安全回退 | 在防止跨材质串漏的同时，避免过严分类在 PSR 边缘造成固定黑点 |

PSR 会把镜面后的命中位置映射到对称虚拟空间，并写出该表面的 normal、
roughness、albedo、material class、motion 和 hit distance。镜面颜色仍是路径
throughput，不被错当成 replacement material 的 demodulation 数据。动态镜面和连续
多镜反射会回退到原有 specular signal，避免不完整的上一帧虚拟变换污染历史。

material class 在 REBLUR 中使用非对称分组：diffuse 将玻璃/发光与普通不透明
材质分开，specular 仅强制隔离发光材质，其余边界交由 normal、roughness 和
hitT 处理。这是实测后的有意取舍：严格的 specular material ID 会在镜面底边
造成可重复的黑色断层。当前没有伪造 history confidence；渲染器还未产生可信的
应用侧 confidence 时，错误的置信度比让 NRD 自行判断更危险。

同一 RTX 4060 Laptop 上的 128 帧固定 Cornell capture 中，镜中地面的可见雪花
已消失，严格 material ID 版本的固定黑点也在分组修正后消失。玻璃的
随机反射/折射二选一已消除，但后续放大检查发现顶面仍有高频残差，
因此不应将此处记为玻璃最终画质验收。这个结论只覆盖当前静态单平面镜；移动镜面、嵌套镜面、
复杂曲面反射以及连续相机运动仍需单独的场景和动态验收。SVGF 和 feature-off
路径没有被切换到这套 NRD 专用路径。

## 玻璃反射/透射分层降噪（2026-08-12）

放大检查确认右侧立方体是闭合玻璃，而非金属镜面。上一版确定性同时追踪
虽然消除了 Fresnel Bernoulli 二选一，但在进入 NRD 前就把反射与透射合并，
仍然要求一组 normal/depth/motion/hitT 表示两个不同虚拟表面。最终修复改为：

- `566016e` 为相机可见玻璃建立两套完整 REBLUR 历史。首界面反射使用
  mirror PSR；主透射光线在穿出玻璃后，用第一个非玻璃命中写出独立的
  diffuse/specular、material factor、normal/roughness、2.5D motion、viewZ 和 hitT。
- 两层分别执行 NRD prep 和 REBLUR，只在降噪完成后合成。Fresnel 和玻璃 tint
  throughput 保留在输入信号中，不会被 replacement material 的解调制重复应用。
- 当前采用可实时重建的两层近似：表面反射 + 主透射。需要额外深度/运动层的
  高阶内反射不再混回主层，避免用错误 guides 换取少量但不稳定的能量。
- `28f351f` 将 Cornell 玻璃底面从地板抬高 `0.005` world units，距离大于当前
  ray epsilon。闭合玻璃底面与地板共面会产生零厚度介质歧义，必须从资产端消除。
