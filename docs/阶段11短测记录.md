## 2026-08-13 静态 RR 稳定性修复

本轮未运行长测，只执行全功能测试、一次 Release 构建、八张 `121..128` 相邻帧 final
capture、两张静态 `specular-motion` guide capture 和一张动画 guide capture。产物位于已忽略
的 `output/stage11/`。

修复后的契约：

- RR noisy HDR 恢复低方差 mixture estimator；Bayer 概率式单-lobe仅保留给 NRD REBLUR。
- RR 提交 `kBufferTypeSpecularMotionVectors`，不再同时提交互斥的
  `kBufferTypeSpecularHitDistance`。
- 当前/上一帧使用同一个 committed triangle 和 barycentrics，并分别应用实例变换及主表面
  反射平面，生成非 jittered、`previous-current`、像素单位的稠密镜面运动。
- 新增 `specular-motion` view；RR debug view 不再隐式关闭 RR/jitter/evaluate。
- `specular-hit-distance` view 改为读取 reconstruction 距离，而不是旧 SVGF G-buffer 距离。

RTX 4060 Laptop、`1280×720` output、`853×480` RR Quality input 的八帧相邻差分结果：

| ROI | 旧 RR raw MAE | 修复后 raw MAE | 变化 |
| --- | ---: | ---: | ---: |
| 全画面 | 0.0976 | 0.0747 | -23.5% |
| 灯光 | 0.2027 | 0.1618 | -20.2% |
| 后墙 | 0.1500 | 0.1136 | -24.3% |
| 镜面 | 0.0939 | 0.0739 | -21.3% |
| 右侧玻璃 | 0.2141 | 0.1754 | -18.1% |
| 地面 | 0.1890 | 0.1542 | -18.4% |

静态 `specular-motion` 的 121/122 帧均为全黑，帧间 changed-pixel ratio 为 0；启用 glTF
刚体动画后非黑覆盖率为约 `0.51%`，证明 guide 不是未绑定的常零资源。修复后仍可能看到比
“NRD + DLSS SR”略高的细颗粒变化：RR 直接处理 1 SPP noisy HDR，而对照路径先经过 NRD
时域降噪再进入 DLSS。这部分不应继续伪装成运动矢量问题，后续应以更好的直接光/间接光采样
（例如 reservoir 重用）降低输入方差。
