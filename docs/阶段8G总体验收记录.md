## 2. 实现摘要

- `DebugView` 使用固定 11 项枚举，CLI、F1 顺序、ToneMap root constant、capture metadata 共用同一映射；resize、F2 和动态控制阻断使用稳定 stderr 诊断行。
- capture 只从 `display_output` 记录 `CopyTextureRegion`，位置在 Total timestamp/PIX event 结束之后、swap-chain copy 之前；readback 由 pending fence 持有，只有 fence 完成后 Map，按 D3D12 footprint row pitch 去除 padding，再原子写 PNG。
- `image_diff` 是独立 binary，Cargo `default-run` 仍为 `ray_tracing_demo`；不兼容尺寸返回非零，成功 stdout 是一行 JSON。
- `VideoMemoryTelemetry` 继续查询实际选中的 adapter 的 `IDXGIAdapter3` local segment，约 500 ms 查询一次；benchmark measurement 固定 60 个 60 秒 checkpoint，统计 start/end/peak usage、minimum budget、peak ratio、valid/failed query。
- 8F 未实现；没有修改 Path Trace、随机采样、Temporal、À-Trous、ToneMap 或动态分辨率控制公式。
